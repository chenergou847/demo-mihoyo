# 主题频次 · B站《鸣潮》玩家评论锚定编码（跨游戏可比版）

> 数据源：`原始数据/wuthering_waves_strict_20260801_20261006.csv`（B站，2026-08-01 ~ 2026-10-06，353 条评论 / 347 名匿名用户 / 121 个来源视频 / 6 个抓取关键词）。
> 编码结果：`observations_coded.csv`（353 行 = 353 条观察，全部条目均已编码，无法归类 0 条）。
> 编码方式：**锚定编码（anchored coding）**——以《原神》作品集 A 的 17 个产品主题 + 5 个非反馈类为锚点分类集，能落入锚点语义的直接复用同名主题；锚点名含《原神》专有内容者不得复用，另立 `鸣潮特有-` 主题；其余无法归入者新建 `鸣潮特有-` 主题。

## 0. 口径

- **主口径 = 去重用户数**（按 `participant_id` 计数，同一用户对同一主题的多次表达只计 1 次）；**条数**为次要口径。
- **证据类型**：`behavior`（描述了实际发生的行为，如“11层打了五遍没过”）> `artifact`（引用数值/统计/消耗清单等数据痕迹）> `stated`（只是说）。本数据集为纯评论文本，`artifact` 共 4 条。
- **置信度**：沿用作品集 A 的三分量 0–6 分制。P = 参与者广度（≤2 位 0 分 / 3–7 位 1 分 / ≥8 位 2 分）；B = 证据强度（全 stated 0 分 / 存在 behavior·artifact 1 分 / behavior 占该主题行数 ≥50% 2 分）；C = 三角验证（本数据集只有 1 种 `source_type`，严格按来源类型数打分则 C 恒为 0，故沿用作品集 A 的折算口径：**独立来源视频 ≤2 个 0 分 / 3–9 个 1 分 / ≥10 个 2 分**）。总分 ≥5 高 / 3–4 中 / ≤2 低。
- **另一条更严口径**来自 `03_报告骨架与编码纪律.md`：「单平台或样本 <10 → 置信度低」。凡去重用户数 <10 的主题均在“样本”列标 ⚠，请按早期信号处理。**本数据集全部来自 B站单平台，任何主题都不具备“高置信度”的多平台条件。**
- **象限/优先级**（与作品集 A 同一规则）：高频（参与者 ≥5 或 占比 ≥30%）× 高影响（平均 impact ≥3.5 或 存在 impact=5）→ P0 高频高影响 / P1 低频高影响 / P2 高频低影响 / P3 低频低影响。**非反馈类不打象限**（表中记为 —）。
- **非反馈**（玩梗与纯情绪、剧情与角色闲聊、代肝与账号交易、信息分享与结论转述、其他游戏与无关话题）单列，**不计入产品结论**，但如实披露规模。
- **同文本同码**：本数据集有 25 条评论与《原神》数据集**逐字相同**，这些条目直接继承原神侧的 theme / intensity / impact / evidence_kind / segment（见第 4 节）。
