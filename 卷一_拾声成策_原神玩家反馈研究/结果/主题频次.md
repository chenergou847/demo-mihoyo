## 0. 口径

- **主口径 = 去重用户数**（按 `participant_id` 计数，同一用户对同一主题的多次表达只计 1 次）；**条数**为次要口径。
- **证据类型**：`behavior`（描述了实际发生的行为，如"手机打不过换电脑才过"）> `artifact`（引用数据/截图/工单痕迹）> `stated`（只是说）。本数据集为纯评论文本，`artifact` 仅 1 条。
- **置信度**：按 `evidence-and-priority.md` 三分量 0–6 分制。P = 参与者广度（≤2 位 0 分 / 3–7 位 1 分 / ≥8 位 2 分）；B = 证据强度（全 stated 0 分 / 存在 behavior·artifact 1 分 / behavior 占该主题行数 ≥50% 2 分）。
  - **C（三角验证）的口径说明**：本数据集只有 1 种 `source_type`（feedback），若严格按"C = 来源类型数"打分，C 恒为 0 分，全部主题最高只能到"中"。因此主表采用方法论第 5 节「来源三角验证（同一种方法、不同参与者/不同来源视频）」折算：**独立来源视频 ≤2 个 → 0 分；3–9 个 → 1 分；≥10 个 → 2 分**；同时并列给出严格口径得分（`严格C` 列）。
  - 判定：总分 ≥5 高 / 3–4 中 / ≤2 低。
  - 另一条更严口径来自 `03_报告骨架与编码纪律.md`：「单平台或样本 <10 → 置信度低」。凡参与者 <10 的主题均在"样本"列标 ⚠，请按其早期信号处理。**本数据集全部来自 B站单平台，任何主题都不具备"高置信度"的多平台条件。**
- **象限/优先级**：高频（参与者 ≥5 或 占比 ≥30%）× 高影响（平均 impact ≥3.5 或 存在 impact=5）→ P0 高频高影响 / P1 低频高影响 / P2 高频低影响 / P3 低频低影响。
- **非反馈**（玩梗、纯情绪、剧情与角色闲聊、广告代肝、其他游戏话题）单列，**不计入产品结论**，但如实披露规模。

## 3. 读表注意事项

1. **声量 ≠ 严重度。** 用户数最多的产品主题 强度膨胀与版本平衡焦虑（51 人 / 52 条）平均 impact 仅 2.17、无 impact=5，而用户数少得多的 深渊11层镇石机制与怪物集火（9 人）平均 impact 达 3.89（全表最高）。两类问题的处置方式不同：前者是预期管理，后者是机制修复。
2. **主题规模受抓取关键词影响，不能读成"全体玩家比例"。** 样本由 6 个关键词抓取（深境螺旋 96 / 太肝 84 / 幽境危战 75 / 强度焦虑 67 / 活动建议 51 / 角色养成 29）。例如 深渊11层镇石机制与怪物集火 的 9 条 **全部**来自「深境螺旋」关键词，强度膨胀与版本平衡焦虑 的 52 条中 32 条来自「幽境危战」+「强度焦虑」。
3. **单期快照。** 深渊11层镇石机制与怪物集火 的 9 条集中在 2026-09-16（深渊更新当日）前后 3 天内（2026-09-16、2026-09-22、2026-09-29），属于同一期深渊的集中反馈，不能推断为长期趋势。
4. **点赞只作参考信号。** 全样本点赞中位数 18、P90 248、最高 2454；少数高赞评论主导可见性，点赞 ≠ 受影响人数（例：深渊11层镇石机制与怪物集火 中最高赞 2454 的一条是玩梗的 11 层短评）。
5. **刷屏会放大规模。** 同一段自选角色长文案出现 5 次（来自 3 名用户，其中 1 名用户重复 3 次），自选五星活动的选择决策 的 11 条中有 5 条是这段复制文案。
6. **分群标注覆盖有限。** 402 条中仅 52 条能从文本判断分群（萌新 17 / 回坑 17 / 硬核 8 / 休闲 4 / 剧情党 4 / 中度 2），其余留空未臆测；分群结论仅作探索性参考。
