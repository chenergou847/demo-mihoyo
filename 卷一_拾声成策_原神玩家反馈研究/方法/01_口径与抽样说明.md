# 作品集 A · 口径与抽样说明（先定口径，再采数据）

> 项目：《原神》线上玩家反馈监测与版本迭代建议报告
> 对口 JD 职责 2：「定期收集线上玩家的反馈并输出分析报告，与研发侧共同制定后续迭代方案」
> 口径冻结日期：⬜（**未冻结不得开始采集**——口径未定不取数）

---

## 一、研究问题（这份报告要支撑什么决策）

> 前置问题：**这次分析要支撑什么决策？**

1. 当前版本玩家**最集中不满/最认可**的是什么？（→ 决定下一版迭代优先级）
2. 这些反馈里，哪些是**系统设计**问题、哪些是**养成**问题、哪些是**活动玩法**问题？（→ 决定该由谁接）
3. 哪些是**情绪**、哪些是**真实体验问题**？（→ 决定能不能直接转成需求）

**目标读者**：研发侧（策划/运营）。**读者要的不是洞察，是可执行建议。**

---

## 二、口径（必须写进报告开头）

| 项 | 取值 | 说明 |
|---|---|---|
| 时间窗 | ⬜ 至 ⬜（建议：近 2 个版本 / 近 30 天） | 明确起止日期 |
| 采集截止 | ⬜ | 与报告生成日一致 |
| 平台 | 米游社 / B站 / 贴吧 / 小红书 / NGA（勾选） | 至少 3 个平台，避免单平台偏差 |
| 语言/地区 | 国服中文内容 | 排除国际服/机翻内容 |
| 纳入规则 | 与《原神》玩法/系统/养成/活动相关的**具体体验描述** | 排除：纯情绪宣泄无具体内容、抽卡炫耀、与版本无关的旧帖 |
| 排除规则 | 广告、代练、账号交易、纯侵权内容、AI 生成通稿 | 另记排除数量 |
| 去重规则 | 同一用户多次重复表达同一观点 → 只计 1 次（按 participant 计频次，不按条数） | |
| 目标样本量 | **200–400 条观察**（来自 ≥100 名不同用户） | 低于 100 名用户时结论标注为"探索性" |
| 强度打分 | intensity 1–5（本人多在意）／impact 1–5（问题发生时的严重度） | 两者分开，不混用 |
| 证据类型 | behavior（做了）> artifact（有截图/数据）> stated（只是说） | 决定证据分 |

**局限声明（必须写进报告）**：
- 样本来自公开社区发帖者，**偏好表达、偏活跃、偏硬核**，不代表全体玩家；
- 无游戏内行为数据（无法核对发言与实际行为是否一致，"说的"≠"做的"）；
- 平台间用户结构不同，跨平台频次对比只能看趋势，不能当精确比例。

## 三、采集关键词（按平台调整）

| 主题方向 | 关键词示例 |
|---|---|
| 版本整体 | 空月之歌、5.x（按当期版本号）、版本更新、前瞻、新版本体验 |
| 系统设计 | 幽境危战、深境螺旋、幻想真境剧诗、命座、圣遗物、秘境、深渊水温 |
| 角色养成 | 月感电、月绽放、月结晶、配队、体系专辅、0+0、金数、练度、培养成本 |
| 活动玩法 | 活动、限时玩法、长草期、日常、树脂、周本、纪行 |
| 反馈诉求 | 建议、希望、吐槽、太肝、太氪、掉率、平衡、强度焦虑 |
| 情感/社区 | 玩家流失、退坑、回坑、社区节奏、内鬼、赋光之人 |

**采集纪律**：
- ❌ 不编造数据、不估算播放量/比例 → 抓不到就写 `null` + 原因码
- ✅ "数据事实"与"分析推断"必须分节
- ✅ 每条洞察标注**证据强度**（多少名用户支持）
- ✅ 引用必须**逐字**，不转述（`validate_findings.py` 会核对引用是否真实存在）
- ✅ 只采**公开可见**内容；`participant_id` 一律匿名编号（U01、U02…），**不出现真实昵称与 UID**

---

## 四、采集合规红线

1. 只采集**公开可见**的帖子与评论；不抓取需登录才能看到的私密内容、不破解、不绕过验证。
2. 报告与简历中**不出现**任何玩家昵称、UID、头像、聊天截图原文。
3. 引用原话最多保留与观点相关的片段，打码处理可识别信息。
4. 不复制大段原文（避免版权与平台规则风险），以"观察 + 短引用"形式呈现。
5. 本作品集为**个人研究作品**，不代表米哈游立场。**公开版本已移除原始评论与视频链接**，仅保留聚合结果与研究者概括；文中不含任何玩家昵称、UID 或可定位个人信息。
